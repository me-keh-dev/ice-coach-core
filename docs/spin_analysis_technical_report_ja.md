# 単眼カメラによるフィギュアスケート・スピン軌跡復元: 技術レポート

**Version:** 3.0
**Date:** 2026-06-20
**Author:** Yoshihide Tsuruha

---

## 概要

フィギュアスケートのスピンにおけるトラベリング（移動量）の定量評価は、従来コーチの目視判断や高価なマルチカメラシステムに依存していた。本文書では、Ice Coachのスピン解析モジュールが採用する技術的アプローチを記述する。本手法は、単一の定点スマートフォンカメラから氷面上の疑似軌跡を復元する——キャリブレーション不要、リンクの基準点不要、サーバー処理不要。

着眼点は、回転中のスケーティング足の2D振動が**既知の周波数**（肩角度解析から算出済みの回転速度）を持つことにある。この性質を利用した**フーリエ分解**により、スケーターの実際のドリフト（移動）を回転成分から分離できる。さらに、氷面上の影検出により、姿勢変化に起因する偽ドリフトを独立に補正する。

---

## 1. 設計思想

スピン解析モジュールは、ジャンプ解析と同一の制約下で動作する：

- **キャリブレーション不要**: カメラの内部・外部パラメータの測定なしに、スマートフォン映像を直接処理
- **リンク基準点不要**: リンク上の既知座標点を使用しない
- **クライアント処理**: MediaPipeとCanvas APIを用いてブラウザ内で完結。サーバー不要
- **定点カメラ**: カメラは固定位置（三脚またはリンクサイド設置）を前提

## 2. パイプライン

```
入力: 定点カメラのスピン動画 + スケーターの身長
       |
       v
[A] 骨格推定 (MediaPipe PoseLandmarker, heavyモデル)
       |  33キーポイント/フレーム, GPU高速化
       |
       +--> [B] 回転速度推定 (肩角度 → RPS)
       |
       +--> [C] スピン区間検出 (腰移動量 + 体幅振動)
       |
       +--> [D] 軸足判定 (多数決投票)
       |
       +--> [E] ブレード接点追跡 (かかと-つま先中点)
       |
       +--> [F] ノイズフィルタ (RPS閾値, ジャンプ距離, 軸外れ検出)
       |
       +--> [G] フーリエ分解 (回転/ドリフト分離)
       |
       +--> [H] 影ベースのドリフト補正
       |
       +--> [I] カメラ俯角推定 (フーリエ振幅比)
       |
       +--> [J] 軌跡の平滑化 + 描画
       |
       v
出力: 氷面軌跡マップ + 動画上ミニマップ + 軸安定性スコア
```

## 3. 回転速度推定

### 3.1 肩角度方式

回転速度（RPS: 毎秒回転数）は、フレーム間の肩角度変化から推定する：

```
sa = atan2(shoulder_R.y - shoulder_L.y, shoulder_R.x - shoulder_L.x)
d = sa[i] - sa[i-1]     (±180°ラッピング処理付き)
rps = |d| × fps / 360
```

MediaPipeの肩ランドマークを使用。時間方向の移動平均でフレーム間ノイズを抑制する。

### 3.2 2D投影補正

2D映像では、投影された肩角度が**1回転あたり2回振動**する（正面向き・背面向きの両方で肩幅が最大に見える）。これにより回転数の計数に系統的な2倍の過大評価が発生する。集計レベルで補正係数を適用して補償する。

### 3.3 累積回転角度

フーリエ分解に必要な累積回転角度は、フレームごとのRPSを積分して算出する：

```
theta[i] = theta[i-1] + rps[i] / fps × 2π
```

## 4. スピン区間検出

### 4.1 3段階検出

**第1段階 — 生セグメント検出**: スライディングウィンドウにより以下の条件を満たすフレームを特定：
- 腰中点の移動量が閾値以下（スケーターがほぼ静止）
- 体幅の標準偏差が閾値以上（体のシルエットが振動＝回転中）

**第2段階 — セグメント結合**: 検出されたセグメント間の短いギャップを結合し、コンビネーションスピン内のポジション変更に対応。

**第3段階 — 最低条件**: 最低限の持続時間と回転数を超えたセグメントのみ有効なスピンとして分類。

## 5. 軸足判定

### 5.1 多数決投票

スケーティング（軸）足は、特にシットスピンで両足が同程度の高さに見える場合、単一フレームからは確実に判定できない。本システムは投票メカニズムを使用する：

1. スピン検出直後の初期フレームで、各フレームがY座標に基づいて軸足を投票（Y大＝氷面に近い）
2. 多数決の結果をスピン全区間で固定
3. 判定結果をフレームごとに保存し、一貫した描画に使用

### 5.2 足首位置の平滑化

正しい足が選択されても、足首ランドマーク位置はポーズ推定のノイズにより毎フレーム変動する。指数移動平均（EMA）で軸足のX座標を平滑化し、安定した可視化を実現。

### 5.3 異常フレームフィルタ

両足首が体の最低点より大幅に上にあるフレームは、ポーズ推定エラーとして分類し描画から除外。高速回転中にMediaPipeが物理的に不可能な骨格構成を出力するケースをフィルタリングする。

## 6. ブレード接点追跡

スピン中の各有効フレームについて、ブレード接点を以下で算出：

```
blade_x = (heel.x + toe.x) / 2
blade_y = (heel.y + toe.y) / 2 + body_height × offset_ratio
```

MediaPipeのかかと・つま先ランドマークを使用。下方オフセットは足首関節とブレード氷面接点との距離を補償する。

## 7. ノイズフィルタ

軌跡復元前に3段階のフィルタでトラッキングノイズを除去：

1. **RPS閾値**: 最低回転速度未満のフレームを破棄（まだ回転していない、または停止済み）
2. **ジャンプ距離フィルタ**: 前フレームから閾値以上位置が飛んだフレームを破棄（ランドマーク追跡失敗）
3. **軸外れ検出**: 足X位置のrunning medianを維持。medianからの持続的な逸脱でスピン終了を検出

## 8. フーリエ分解

### 8.1 信号モデル

スピン中のスケーティング足の2D位置は以下でモデル化できる：

```
x(t) = center_x(t) + radius × cos(theta(t))
y(t) = center_y(t) + radius × sin(theta(t)) × sin(alpha)
```

- `center(t)` = 氷面上の実際の位置（ドリフト成分）
- `radius` = 回転軸からブレード接点までの距離
- `theta(t)` = 累積回転角度（3.3節で算出済み）
- `alpha` = カメラ俯角

### 8.2 スライディングウィンドウ分解

各サンプル点を中心とした約1回転分のウィンドウで：

```
center_x = (1/N) × Σ x[j]                    (DC成分 = ドリフト)
A_x = (2/N) × Σ x[j] × cos(theta[j])         (フーリエ余弦係数)
B_x = (2/N) × Σ x[j] × sin(theta[j])         (フーリエ正弦係数)
radius_x = sqrt(A_x² + B_x²)                  (回転振幅)
```

回転半径はキャップ値で制限し、フリーレッグの振動が推定を汚染するのを防止。

### 8.3 Y軸安定化

垂直方向のドリフト成分（`center_y`）はスピン全体の中央値に固定。2Dにおける垂直変動は姿勢変化（シット⇔アップライト）に起因するものであり、氷面上の実際の移動ではない。

### 8.4 鳥瞰図復元

氷面軌跡は、分離されたドリフトと回転成分を組み合わせて復元：

```
x_ice = center_x + radius_x × cos(theta)
z_ice = radius_x × sin(theta)
```

Z軸はX方向の回転半径のみを使用。`center_y / sin(alpha)` は姿勢起因の垂直変動により信頼性が低いため使用しない。

## 9. 影ベースのドリフト補正

### 9.1 課題

姿勢変化（例：アップライトからシットスピンへの遷移）は、スケーターが静止していてもフーリエ中心位置をシフトさせうる。これは復元軌跡に偽ドリフトを生じさせる。

### 9.2 影検出

氷面上のスケーターの影が、位置のグラウンドトゥルース情報を提供する：

1. スピン開始前の立位フレームを選択
2. MediaPipeで足位置と体のバウンディングボックスを検出
3. 前処理で影のコントラストを強調
4. 体のバウンディングボックス領域をマスク
5. 足元以下の氷面で、適応的閾値により暗い領域を影として特定
6. モルフォロジー処理でノイズ除去

### 9.3 ドリフト固定

スピン中の影の水平移動範囲が閾値未満の場合、全フーリエフィットのドリフトをゼロに固定。影がスピンの静止を確認し、見かけの中心ドリフトはアーティファクトと判断する。

### 9.4 カメラ俯角推定

影はカメラ俯角の独立した推定を提供する：

```
sin(alpha) = shadow_length / body_height
```

フーリエ振幅比（`avg_ry / avg_rx`）と相互参照。影由来の値は物理的根拠がより強いため、利用可能な場合はこちらを優先。

## 10. 軸安定性スコア

### 10.1 統合メトリクス

軸安定性スコアは2つの成分を単一の品質指標に統合する：

**成分1 — COGオフセット**: 全身重心と軸足位置の距離（フレーム幅で正規化）。COGは解剖学的体節質量比（頭部、体幹、上肢、下肢）を用いた加重平均で算出。

**成分2 — 体幹傾き**: 体幹中心線（肩中点→腰中点）の軸足鉛直線からの水平偏位。

**遠心力許容**: 高RPS時は、予期される遠心力偏位を考慮して追加のオフセット許容を適用。

### 10.2 スコアリング

統合オフセットをアラインメントレベル（良好 / 許容 / 不良）に分類し、対応する色で表示。閾値はユーザー選択の難易度レベルでスケーリングし、異なるスキルレベルに対応。

## 11. 軌跡の平滑化と描画

### 11.1 後処理

最終的な軌跡点は移動平均で平滑化し、ポーズ推定由来の残余ノイズを除去。

### 11.2 軌跡マップ

動画下部にSVG要素として表示：
- 線の色はセグメントごとの軸安定性スコアをエンコード
- Catmull-Romスプライン補間で滑らかな曲線を描画
- 現在の再生位置をハイライトし、動画と同期

### 11.3 動画上ミニマップオーバーレイ

同一の軌跡データを動画キャンバスの左下に円形ミニマップとして描画：
- 過去の軌跡：明るい色
- 未来の軌跡：暗い色
- 現在位置：ドットでマーク
- 動画再生中にリアルタイム更新

## 12. 制限事項

1. **単眼カメラの奥行き曖昧性**: Z軸（氷面の奥行き方向）はフーリエY振幅比から推定しており、カメラがほぼ水平に近い角度では精度が低下
2. **RPS推定への依存**: 軌跡精度は2D肩角度からのRPS推定に依存し、特定のスピンポジション（特に肩が部分的に隠れるシットスピン）ではノイズが増加
3. **メートル単位ではない**: カメラキャリブレーションなしでは、軌跡は相対的な移動パターンを示すが、メートル単位の絶対距離は表示不可
4. **定点カメラ限定**: 現リリースは固定カメラ位置を前提
5. **姿勢依存ノイズ**: 影補正にもかかわらず、急激な姿勢変化が小さな軌跡アーティファクトを生じさせる場合がある

## 13. 検証

本手法は、複数種類のスピン（単一ポジション、コンビネーション）と定点カメラ条件のテスト動画群で検証した。フィギュアスケートコーチによる定性評価で、復元された軌跡形状が観察されるトラベリングパターンと一致することを確認。

## 14. 関連研究

### フィギュアスケートのスピン解析

スピン評価に関する先行研究は、主にプロフェッショナルなモーションキャプチャシステムまたはマルチカメラセットアップに依存してきた。マーカーベースのシステムを用いた実験室研究では高精度なスピン生体力学の計測が行われているが、管理された環境と専用機器が必要。

### スポーツにおける単眼ポーズ推定

単眼ポーズ推定の近年の進歩により、単一カメラからの骨格検出が可能になった。スポーツ解析への応用は、動作認識やポーズ分類に集中しており、軌跡復元の研究は少ない。

### 本研究の位置づけ

Ice Coachのスピン軌跡復元は、既存ツールのギャップに対応する：
- プロ機材の代わりにコンシューマー機器（スマートフォン）を使用
- マルチカメラ幾何学の代わりに信号処理（フーリエ分解）で回転とドリフトを分離
- 環境的手がかり（氷面の影）を独立したドリフト検証に活用
- サーバー依存なしに完全にクライアントサイド（ブラウザ）で処理
