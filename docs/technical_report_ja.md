# 単眼カメラによるフィギュアスケート3D軌道復元: 技術レポート

**バージョン:** 5.0
**日付:** 2026-06-02
**著者:** 鶴羽 佳秀 (Yoshihide Tsuruha)

---

## 概要

本文書は、Ice Coachが実装する「単眼カメラ映像からのフィギュアスケーター3D軌道復元手法」の技術的アプローチを記述する。本手法はカメラキャリブレーションを必要とせず、スマートフォンで撮影した動画から氷上の位置、ジャンプ軌跡、滑走経路を推定する。

---

## 1. 設計思想

Ice Coachは以下の制約のもとで3D軌道復元を実現する:

- **カメラキャリブレーション不要**: スマートフォンで撮影した動画をそのまま処理
- **リンク基準点不要**: リンク上の既知座標点を使用しない
- **クライアントサイド処理**: ブラウザ上で完結し、サーバーを必要としない

## 2. 全体構成

```
入力: 単眼カメラ動画 + スケーターの身長
       |
       v
[A] 骨格推定
       |  各フレームの身体キーポイント（GPU加速）
       |
       +--> [B] ジャンプ検出（重心解析）
       |
       +--> [C] 奥行き推定（骨格の画素サイズ）
       |
       +--> [D] 3D位置復元（ピンホールカメラモデル）
       |
       +--> [E] 軌跡平滑化・描画
       |
       v
出力: 3D軌跡 + 骨格オーバーレイ + 3Dリンクビュー
```

## 3. 骨格推定

姿勢推定モデルが各動画フレームから身体のキーポイントを検出する。複数人が映っている場合、IoUベースのトラッキングで対象スケーターをフレーム間で追跡する。

## 4. ジャンプ検出

ジャンプは重心（肩と腰の中間点）の垂直位置から検出する。平滑化された垂直方向の信号を計算し、十分な突出度を持つ局所ピークをジャンプの瞬間として特定する。離氷・着氷フレームは周囲の信号から決定する。

## 5. 氷面射影

足首の2D画面座標を、レイと氷面平面の交差により氷面上に投影する。正規化画面座標 `(u, v)` と仮定されたカメラパラメータ（高さ、チルト角、焦点距離）から:

```
ray_direction = (u/f, -(v/f × cos(tilt) - sin(tilt)), v/f × sin(tilt) + cos(tilt))
t = -camera_height / ray_y
ice_position = t × (ray_x, ray_z)
```

フレーム間の氷面上の変位は数値微分（ヤコビアン）で算出する:

```
dz/dv ≈ (z(v + ε) - z(v - ε)) / (2ε)
```

これにより3Dリンクビューで使用される氷面上の軌跡が得られる。

## 6. 奥行き推定

ピンホールカメラモデルを用いて、骨格の見かけの画素サイズからカメラ〜スケーター間の距離を推定する:

```
Z = L_real × f / L_observed
```

ここで:
- `L_real`: 既知の身体部位の実寸（入力された身長と解剖学的比率から導出）[m]
- `f`: 焦点距離（標準的なスマートフォンの画角から推定）[px]
- `L_observed`: 現在のフレームにおける身体部位の画素長 [px]

観測された身体部位の長さは、回転による短縮のアーティファクトを除去するため、中央値フィルタで前処理される。

## 7. 3D位置復元

2D画面位置と推定された奥行きからワールド座標を復元する:

```
X = (u - u₀) × Z / f
Y = (v - v₀) × Z / f
```

ここで `(u, v)` は画面位置、`(u₀, v₀)` は主点（画像中心）。標準的なピンホールカメラの逆投影である。

## 8. 高さ算出

ジャンプの高さは自由落下の物理公式から滞空時間のみで決定する:

```
H = g × T² / 8
```

ここで `g` は重力加速度、`T` は計測された滞空時間。

## 9. 後処理

1. **中央値フィルタ**: 回転時の身体計測値のスパイクノイズを除去
2. **ガウシアン平滑化**: 接地中の氷上座標のフレーム間ジッターを低減
3. **曲率制約**: スケーティングの物理に基づく最小旋回半径を適用
4. **速度クランプ**: 物理的に妥当な範囲の最大速度・最大加速度を制限

## 10. 軌跡描画

ブレード接地点をフレームごとに追跡し、以下の処理を経て描画する:
1. スパイク除去のための中央値フィルタ
2. ノイズ低減のための移動平均
3. 滑らかな曲線描画のためのスプライン補間

描画された軌跡は動画上に合成され、動画フレームと同期して表示される。

## 11. スケール校正

セグメンテーションモデルがスケーターの身体領域を検出する。入力された身長と組み合わせることで、ピクセルとメートルの変換係数を得る。

## 12. 遮蔽への対応

- 骨格推定が失敗したフレームは無効としてスキップ
- 有効フレーム間は補間で軌跡を接続
- ジャンプ区間が検出された場合、氷上位置の推定は適切に調整

## 13. 回転不足(アンダーローテーション)検出

### 13.1 概要

回転不足検出は、ジャンプ着氷時の回転不足角度を定量化する。ISU（国際スケート連盟）のジャッジは目視で回転不足を評価するが、標準化された計算手法は公開されていない。Ice Coachは、MoCapベースの体の向き計測による新しい自動化アプローチを導入する。

### 13.2 手法

3Dモーションキャプチャ（MoCap）による骨格再構成から、XZ平面（氷面）上の肩の向きを計測する。

**ステップ1: 体の向き角度**

肩ライン（LeftShoulder → RightShoulder）の法線をMoCap世界座標系のXZ平面に投影して体の向きを算出する:

```
dx = RightShoulder.x - LeftShoulder.x
dz = RightShoulder.z - LeftShoulder.z
facing_angle = atan2(dx, -dz)
```

3D空間での回転を捉えるため、体がカメラに正対/背面を向いた際に2D肩角度で生じる±180°フリップのアーティファクトを回避できる。

**ステップ2: 安定角度（基準方向）**

着氷後にスケーターが安定した方向を向いた時の角度を、着氷後の短い時間窓における体の向き角度の**平均**として算出する:

```
settled_angle = mean(facing_angle[t_land + t_start ... t_land + t_end])
```

複数フレームの平均をとることで、GPUベースの姿勢推定に内在する非決定性を吸収する。

平均化の前に角度のアンラップ処理を行い、±180°境界を正しく処理する。

**ステップ3: 不足角度の算出**

生の不足角度は、着氷時の体の向きと安定角度の角度差である:

```
raw_deficit = |angle_diff(facing_at_landing, settled_angle)|
```

**チェックアウトオフセット**を差し引く。これはブレードのロッカーカーブ上での正常な着氷後回転であり、ISUジャッジも回転不足とは見なさない:

```
deficit = max(0, raw_deficit - checkout_offset)
```

**ステップ4: ISU基準による分類**

| 記号 | 不足角度範囲 | GOE影響 |
|------|------------|---------|
| OK | 45°未満 | なし |
| q | 45° 〜 89° | GOE -1 |
| < | 90° 〜 179° | GOE -2〜-3, 基礎点×0.80 |
| << | 180°以上 | GOE -3〜-4, 基礎点1回転下 |

### 13.3 設計上の判断

| 課題 | 解決策 |
|------|--------|
| 2Dのheel-toeランドマークがノイズ大（数ピクセル差） | MoCap 3D肩方向を代わりに使用 |
| 2D肩角度が回転中に±180°でフリップ | MoCap世界座標（XZ平面）を使用 |
| MoCap腰ラインのカメラパースドリフト | 肩ライン使用（滑走中はより安定） |
| GPU推論の非決定性 | 時間窓でsettled角度を平均化 |
| 正常な着氷後回転が不足として計測される | チェックアウトオフセットを差し引き |
| PC/スマホの精度不一致 | heavyモデル+60fpsを全デバイスで統一 |

### 13.4 制約

- MoCapの肩位置の精度に依存する。体がカメラに正対/背面を向くと精度が低下する
- チェックアウトオフセットは経験的に決定された値であり、ジャンプの種類やスケーターにより異なる可能性がある
- ISUジャッジは着氷時のブレードの向きを評価するが、本手法は体（肩）の向きを代理指標として使用している
- 動画デコードとGPU推論の非決定性により、解析結果は実行ごとに±5°程度変動しうる
