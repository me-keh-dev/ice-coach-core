# スマホ1台でスピンの軌跡を出したかった話

---

ジャンプの軌跡が出せるようになって、こう言われた。

**「スピンでも出せない？」**

スピンのトラベリング（回転中に氷上を流れること）はGOE減点対象。コーチは見ればわかる。でも選手本人は回ってるから見えない。

スマホの動画からスピンの軌跡を出せたら、練習が変わるんじゃないか。

やってみた。

---

## 足を追ったら紐になった

AIで骨格検出して、軸足の位置を毎フレーム記録して、線でつなぐ。これでいけるだろうと。

出てきたのは足元にぐちゃぐちゃに絡まった紐みたいなやつだった。

回転するたびに足の見かけの位置が左右に振れる。実際には動いてないのに。カメラから見ると回転と移動の区別がつかない。

スムージングかけたら紐はほどけた。でも軌跡にはならなかった。

## 11回失敗した

位相相関、SIFT、AKAZE、ORB、テンプレートマッチング、ECC、光学フロー（全画面）、光学フロー（上半分）、腰の累積、Y増幅、足首→腰変更。

全部ダメだった。

共通の原因は1つ。**2D映像では回転と移動が分離できない。**

## AIに聞いても答えは出なかった

Claude、ChatGPT、いろいろ壁打ちした。論文も読んだ。でも「単眼定点カメラでスピン中の氷上移動を追跡する」なんてニッチすぎて先行研究がない。

AIは既存の知識を組み合わせるのは得意だけど、存在しない解法は出してくれない。

結局、自分で考えるしかなかった。

## 回転の周波数を引き算する

ある日ふと気づいた。

回転する足は、カメラから見るとコサイン波になる。その周波数は回転速度（RPS）で、これは肩の角度変化からもう計算できてる。

**周波数がわかってるなら、引き算できるじゃん。**

```
足の位置 = 移動 + 半径 × cos(回転角度)
```

フーリエ分解。大学1年で習うやつ。DC成分が移動、第1高調波が回転。

コード書いて動画入れたら、ぐちゃぐちゃの紐が消えて、12秒間で左に3cmドリフトする滑らかな線が出た。

コーチに見せたら「そうそう、これこれ」って。

## 影がもう1個のカメラだった

ただ問題があって、シットスピンに入ると姿勢変化で足のランドマークがずれて偽のドリフトが出る。

どうやって姿勢変化と本当の移動を見分けるか。

氷の上を見たら答えがあった。**影。**

影は物理に忠実で、スケーターがしゃがんでも影の位置は変わらない。影が動いてなければスケーターは移動してない。

影検出して、動いてなかったらドリフトをゼロに固定。偽の移動が消えた。

おまけに影の長さからカメラの俯角も出せて、鳥瞰図への変換パラメータがタダで手に入った。

## 今、ブラウザで動いてる

1. 軸足追跡（かかと-つま先の中点、多数決で足を固定）
2. ノイズ除去（RPS閾値、ジャンプ距離フィルタ）
3. フーリエ分解で回転を除去
4. 影でドリフト補正
5. 平滑化

サーバーなし。キャリブレーションなし。リンクの寸法も不要。スマホで撮った動画1本だけ。

完璧な軌跡じゃない。2Dデータと数学で組み立てた疑似軌跡。でも練習では十分使える。

**「ほら、足元流れてるの見える？」**

これが、スマホだけで言えるようになった。
