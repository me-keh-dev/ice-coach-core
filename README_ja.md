# Ice Coach Core

AIフィギュアスケートジャンプ解析 — 技術ドキュメント・アルゴリズム設計

## 概要

Ice Coachのフィギュアスケート解析エンジンの技術ドキュメントです。アルゴリズムの解説と設計思想を公開しています。**ソースコードは準備中です。**

Ice Coachは、スマートフォン1台で撮影した動画からジャンプの3D軌跡復元・回転不足判定を行います。キャリブレーション不要、基準点不要、センサー不要。全てブラウザ内で動作します。

**Try it:** https://ice.coach

## 主な特徴

- **キャリブレーション不要**: カメラの内部・外部パラメータの事前計測が不要
- **リンク基準点不要**: 氷面上の既知座標を使用しない
- **スマートフォン1台**: マルチカメラやウェアラブルセンサーが不要
- **ブラウザ動作**: クライアントサイドでブラウザ上で完結（サーバー不要）
- **物理学に基づく**: ジャンプの高さは滞空時間から運動方程式で算出

## 仕組み

```
入力: 単眼カメラ動画
       |
       v
[A] 骨格推定 (MediaPipe Pose)
       |
       +--> [B] 水平位置復元 (氷面射影 + ヤコビアン微分)
       |         → 氷面上の2D軌跡 (x, y)
       |
       +--> [C] ジャンプ検出 (CNN分類器)
       |         → 離氷・着氷フレーム、滞空時間T
       |
       +--> [D] 高さ算出 (物理公式)
       |         → h(t) = (g/2) * t * (T - t)
       |
       +--> [E] 奥行き推定 (身体サイズ比率)
       |         → カメラ距離（概算）
       |
       +--> [F] 回転不足検出 (MoCap肩方向計測)
                 → ISU基準の判定 (OK/q/</<<)
       |
       v
出力: 3D軌跡 + 速度 + 距離 + 回転不足判定
```

## 技術的アプローチ

### 水平位置: 接地制約 + ヤコビアン微分投影

足首の画像座標を固定仮定のカメラモデルで氷面に射影。フレーム間の移動量はヤコビアン微分で算出。

### 高さ: 物理公式による直接計算

滞空時間Tのみからジャンプの高さを一意に決定:

```
H_max = g * T^2 / 8
h(t) = (g/2) * t * (T - t)
```

滞空時間のみから高さを一意に決定する。

### 奥行き: 人体計測学的身体サイズ比率

身体部位（例: 背骨の長さ）のピクセルサイズと、解剖学的に既知の人体比率を比較してカメラ距離を逆算。

```
depth = 背骨実長(m) * 焦点距離(px) / 背骨ピクセル長
```

### 回転不足検出: MoCap肩方向計測

3Dの体の向きを用いてジャンプ着氷時の回転不足を定量化する独自手法。

**体の向き角度**: 肩ライン（LeftShoulder → RightShoulder）の法線をMoCap世界座標系のXZ平面（氷面）に投影:

```
facing_angle = atan2(dx_shoulder, -dz_shoulder)
```

**安定角度**: 着氷後にスケーターが安定した方向。着氷後の短い時間窓における向き角度の平均。複数フレームの平均をとることでGPU推論の非決定性を吸収する。

**不足角度の算出**:

```
raw_deficit = |angle_diff(facing_at_landing, settled_angle)|
deficit = max(0, raw_deficit - checkout_offset)
```

チェックアウトオフセットは、ブレードのロッカーカーブ上での正常な着氷後回転を差し引く。ISUジャッジもこの回転は回転不足とは見なさない。

**ISU基準による分類**:

| 記号 | 不足角度 | 影響 |
|------|---------|------|
| OK | 45°未満 | なし |
| q | 45°〜89° | GOE -1 |
| < | 90°〜179° | GOE -2〜-3, 基礎点×0.80 |
| << | 180°以上 | GOE -3〜-4, 基礎点1回転下 |

### 軌跡描画: 物理ベースのジャンプ弧

- **地上フレーム**: ブレードエッジ位置（heel/toe最低点+足首オフセット）
- **空中フレーム**: 離氷・着氷位置から放物線弧を算出 — 飛行中の不安定な足ランドマークは使用しない
- **スパイク除去**: 物理速度制約+近傍偏差による外れ値検出

### 後処理: 物理制約

- **空中区間の平滑化**: ジャンプ中の水平座標はスムーズに補間
- **ガウシアン平滑化**: 接地中のXZ座標のノイズ除去
- **曲率制約**: スケーティングの物理に基づく最小旋回半径
- **速度クランプ**: 物理的に妥当な最大速度・最大加速度に制限
